# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users and purpose
Miles DiPaola is a working DJ with years of event footage spread across drives and cards. He needs to see a manageable set of real previews, keep promising footage, and build corporate/brand booking proof for Instagram and the Savvy Sounds website. These facts are confirmed in the current conversation; no new interview is needed for this scoped expansion.

## Operating context
A local Mac browser, with the drives connected. The existing Savvy Review page supplies the incumbent visual and interaction language. The preview library expands that review workflow; it does not replace the underlying editing pipeline.

## Capabilities and constraints
Photos and video share an event library. Preview availability and source location remain visible. Keep, Maybe and Pass are reversible choices, not file operations. Original files remain untouched. Cloud-only files are never downloaded by browsing. No paid grading, publishing, new dependencies or external service calls are part of this surface. Some event labels are unverified folder names.

## Accessibility
Native playback controls, visible keyboard focus, touch-sized choices, readable contrast and responsive phone/desktop layouts are required. Sound never starts automatically.
